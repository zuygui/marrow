Source: `std/x509.mw`.

Parses DER certificates, loads PEM bundles and verifies a chain against a set of trust anchors, including validity dates, CA constraints, key usage and host name matching.

X.509 certificates (RFC 5280): parsing, hostname matching, chain building checks and a PEM trust store.  Supported: RSA (PKCS#1 v1.5) and ECDSA (P-256 / P-384) signatures with SHA-1/256/384/512, and the extensions basicConstraints, keyUsage, extKeyUsage and subjectAltName.  Unknown \*critical\* extensions make a certificate unacceptable.

### `x509_verify_chain`

```marrow
fn x509_verify_chain(chain: *VecPtr, anchors: *VecPtr, host: *u8, now: i64) -> i64
```

Checks `chain` (leaf first; a VecPtr of \*Cert as sent by the server) against `anchors`, for `host` (null skips the name check) at Unix time `now`. Returns X509\_OK or an X509\_E\_\* code.
