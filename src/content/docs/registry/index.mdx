Packages published to the Marrow registry. Add one to your project with `marrow add <name>`, and publish your own with `marrow publish` (see [Projects and packages](/marrow/guides/packages/)).

This list is read from the registry when the page opens, so a new package appears here without the documentation being rebuilt.
